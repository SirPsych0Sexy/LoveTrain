## LoveTrain

Un simple fuzzer hecho como proyecto de ratos libres.

### Como usarlo

Simplemente consta de 2 parámetros.

#h/green**-w** En este parámetro se encarga de especificar el directorio, puedes poner cualquiera siempre y cuando especifiques la ruta.

-u: En este parámetro tienes que especificar la URL a la que le quieres hacer un escaneo, de forma opcional puedes añadir el http o https y el / debido a que el programa se encarga de añadirlo de forma automática.
